# TripFlow

## 한 줄 소개
여행 일정, 지출, 체크리스트, 파일 관리를 함께 다루는 웹 서비스 실험 저장소입니다.

## 저장소 성격
- 분류: 웹 / 서비스 실험
- 목적: 일정 관리와 여행 관련 기능을 한 서비스로 구성
- 핵심 기술: Go, JavaScript, Frontend, SQL Migration

## 포함된 기능
- 일정 관리
- 지출 관리
- 체크리스트 관리
- 파일 업로드 및 관리

## 구조
- `api/`: API 엔드포인트
- `frontend/`: 사용자 화면
- `migrations/`: DB 마이그레이션
- `docs/`: 배포 및 연동 문서

## 메모
현재 구조를 기준으로 기능을 계속 정리하고 있는 저장소입니다.

## 실행 상태 및 Redis 설정

- 2026-09-11 기준 기존 Redis Cloud 서비스의 접근 가능 여부는 미확인입니다. 이전 자격 증명의 만료나 데이터베이스 삭제가 확인된 것은 아닙니다.
- 기존 자격 증명은 재사용하지 않습니다. Redis를 사용하는 기능을 실행하려면 본인이 관리하는 Redis의 연결 정보를 서버 환경변수 `REDIS_URL`로 제공해야 합니다.
- 예시: `REDIS_URL=rediss://default:REPLACE_WITH_YOUR_PASSWORD@redis.example.com:6379` — 실제 접속할 수 없는 설명용 값입니다. 실제 주소, 포트 및 TLS 설정은 사용 중인 Redis 설정을 따르세요.
- 실제 비밀값은 저장소나 프론트엔드 코드에 넣지 마세요. 배포 환경의 비밀 환경변수로 관리하세요.
- 빌드 성공은 Redis 연결이나 서비스 전체의 정상 동작을 보장하지 않습니다. 현재 배포본을 정상 동작이 검증된 데모로 간주하지 마세요.

추가 안내는 [배포 문서](DEPLOYMENT.md#redis-연결-복구-전-확인사항)를 참고하세요.
