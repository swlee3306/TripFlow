# TripFlow

## 한 줄 소개
여행 일정, 지출, 체크리스트, 파일 관리를 함께 다루는 웹 서비스 실험 저장소입니다.

## 저장소 성격
- 분류: 웹 / 서비스 실험
- 목적: 일정 관리와 여행 관련 기능을 한 서비스로 구성
- 핵심 기술: Go, JavaScript, Frontend, SQL Migration

## 포함된 기능
- 일정 관리
- 지출 관리
- 체크리스트 관리
- 파일 업로드 및 관리

## 구조
- `api/`: API 엔드포인트
- `frontend/`: 사용자 화면
- `migrations/`: DB 마이그레이션
- `docs/`: 배포 및 연동 문서

## 메모
현재 구조를 기준으로 기능을 계속 정리하고 있는 저장소입니다.
